# TransportNSW-PowerBI-Report
SQl query to explore NSW transportation & 2 customized Dashboards using PowerBI. 

Download Dashboard pbix file (2 sheets) and filter the insight you wanna get to know

The dashboards are designed to two primary sectors, the former is for manager who want to have an overview of NSW transportation status at the first glance where the latter cater for our commuters who looking forward the peak hours or the affordable ban gap for their trip.
